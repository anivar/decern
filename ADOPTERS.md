# Adopters

**No production deployments are known.** decern is pre-1.0.

This file exists so that claim stays checkable. A project's own account of who uses it is the
easiest thing to inflate and the hardest for a reader to disprove, so the honest state is written
down and kept current rather than left to be inferred from silence.

## Being listed

Open a pull request adding a row, or say so in
[Discussions](https://github.com/anivar/decern/discussions/categories/q-a) and it will be added for
you. Nothing is listed without the adopter's permission, and a listing can be removed at any time
by asking.

| Organisation | Since | What it is used for | Contact |
|---|---|---|---|

Evaluating it and not ready to be named is entirely reasonable, and saying so privately is still
useful — knowing where it is being tried shapes what gets built next. `SECURITY.md` has a private
contact route.
