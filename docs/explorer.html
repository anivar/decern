How decern establishes a caller

decern will not start until the deployment says how its callers are established. The five postures diverge only in how the caller is proven; everything downstream — the solver-proven kernel, the recorded decision, the fail-closed serve — is the same for all of them. Pick a posture and step the request through it.

Grounded in the standards registry the code is held to. Steps and section citations come from decern's own conformance records for RFC 9068, RFC 9421, SPIFFE JWT-SVID and draft-hardt-oauth-aauth-protocol-11. Verification only — decern issues no tokens. This is an explainer; read the code for the exact behaviour.
