- **A `--features postgres` build verifies the database's certificate chain with `rustls-webpki` 0.103.16.** The pinned 0.103.15 could accept a certificate path through distrusted emSign intermediates whose private keys are now public ([RUSTSEC-2026-0382](https://rustsec.org/advisories/RUSTSEC-2026-0382)). Only a build with the Postgres head store carries that crate; the release binaries and every default build pull no TLS stack and are not affected. Authored by @anivar.
