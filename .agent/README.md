# .agent

The working method for agents and humans in this repo — how to make a change here, not what
has been changed. Method only: no project knowledge, no history, no accumulated intel lives
in this tree. Today that is `standards/` — the registry of external specs decern implements
and the rule for staying conformant. Read the current spec before you touch its surface, and
verify before you commit (see `../AGENTS.md`).
